What the architect builds, and where a business user can reach it. Every component is a stock Microsoft product or a SQL view. THE ARCHITECT OWNS

  • Three SQL views — the entire published surface and the security boundary. Base tables stay unreachable.
  • dab-config.json — entities, field lists, which tools exist. No code change to alter what the model can reach.
  • ~120 lines of orchestration — route, execute, phrase. Not an agent framework; no query logic.
  • The model — deployment, version, region, content filters.
  • Hosting, network and identity — container, private endpoint, managed identity, gateway.
  • The agent that fronts it — nothing is consumable until you build or configure one.
